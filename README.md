# BioMovement Funil Dashboard

Dashboard em tempo real do funil comercial da BioMovement conectado ao Supabase.

## Deploy no Vercel (1 minuto)

1. **Fork este repositório** pro seu GitHub
2. **Conecta no Vercel:**
   - Va em vercel.com
   - Clica "New Project"
   - Seleciona este repositório
   - Clica "Deploy"

Pronto! Dashboard rodando em `seu-app.vercel.app`

## Variáveis de Ambiente

Já preenchidas no `.env.local`:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

## Usar Localmente

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`

## Features

- ✅ Visualização em tempo real
- ✅ Editar deals direto no dashboard
- ✅ Deletar deals
- ✅ Busca por empresa/município
- ✅ Stats automáticos
- ✅ Sincronização com Supabase
